# THE FOCUX BRAIN — the powers it grants to any agent or business

This is the manifesto. THE FOCUX is not a tool you install: it is a set of
POWERS that any coding agent, any business, any operator can adopt in one
command (`focux attach`). Every power keeps the discipline: the LLM proposes,
the gate decides, the human approves REVIEW, and everything is measured.

## Poder 1 — VER el mundo real (absorb)
The brain does not work on vibes. `focux absorb` pulls REAL signals from
GitHub (what grows), Hugging Face (what comes), and X (what works) and
converts them into facts the brain reasons with. Every draft automatically
receives `## Absorbed signals (REAL data)`.

## Poder 2 — Metas que se miden (objective)
Intelligence without goals is noise. The brain carries measurable objectives
with KPIs, targets, deadlines, gaps and momentum (`focux objective`). It
never pretends there are goals when there are none — it says so.

## Poder 3 — Inteligencia dirigida (focus / ask)
Any agent that enters an attached project is smarter in its first second:
`.focux/focus.md` (or the `focux_focus` MCP tool) tells it OUR real goals,
their gaps, the evidence, the work state and the tier — and orders it to be
smart ONLY toward those goals. `focux ask "<anything>"` answers any question
with that directed intelligence.

## Poder 4 — Estrategia con evidencia (drive / insights)
The brain proposes concrete next actions per objective, grounded in the real
signals (`focux objective drive`), and surfaces evidence-based opportunities
(`focux insights`). Every proposal is gated BEFORE it becomes a plan: the
brain proposes with intelligence but never auto-authorizes.

## Poder 5 — Experiencia mundial (experts)
The brain carries world-class playbooks — content, social media, ecommerce,
monetization, digital opportunities (`playbooks/`) — and an Expert Panel
(`focux expert`) that answers as a top-tier specialist and reviews drafts
with a strict PASS/REVISE quality gate before anything ships.

## Poder 6 — Trabajo que sobrevive (work)
Work that outlives one context window goes through explicit stages with
durable state in the project (`.focux/work/`): frame -> plan -> execute ->
verify -> verified. The human approving the SPEC is the product review; no
model gate stands in for it. Verified is terminal and sessions open quiet.

## Poder 7 — Seguridad que no negocia (gates)
The money-gate decides ALLOW/REVIEW/DENY with code, not opinion: money is
never auto-approved, tainted never auto-approves, survival tiers change
effort never authorization, protected files are never modified, and every
action is audited append-only. A winner never breaks the rules to win.

## Poder 8 — Mejora continua (evolution / daily)
The brain analyzes what executed and proposes fixes and crystallizations
(`focux evolve`), and runs its daily ritual (`focux daily`): VER -> ENFOQUE
-> ESTRATEGIA -> OPORTUNIDADES -> VIGILANCIA. Momentum = measured progress
rising, never vibes.

## Poder 9 — Adopción universal (attach / install / MCP)
One command mounts the brain into any project and configures EVERY coding
agent (Claude Code, Codex, Cursor, Aider, Copilot, Gemini): `.focux`
contract, per-agent configs, and the MCP bridge with 19 tools. `focux
install` makes the CLI global on any machine. Any agent, any business, any
provider — the powers are the same.

---

**The whole in one line:** THE FOCUX turns any agent into a business
intelligence that sees the real world, aims at real goals, thinks with
evidence, carries world-class expertise, works beyond sessions, never breaks
the rules, improves every day, and is adoptable anywhere.
